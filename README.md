## AuraKey - Менеджер паролей с облачной синхронизацией
Этот проект был разработан в рамках учебного проекта по дисциплине "Мобильная разработка", сочетая в себе безопасный инструмент для хранения паролей и отличную возможность применить полученные навыки работы с современными технологиями шифрования и облачной синхронизации.

### 🎯 Возможности

🔐 Безопасное хранение паролей – добавление и хранение учетных данных с детализацией (название, логин, пароль, заметки, категория)

🔒 End-to-end шифрование – все данные шифруются на устройстве перед отправкой в облако с использованием AES-256

⚡ Умная генерация паролей – создание сложных уникальных паролей по требованиям безопасности

✅ Визуальная валидация – индикация соответствия пароля требованиям безопасности в реальном времени

☁️ Облачная синхронизация – ваши пароли доступны на всех устройствах после входа в аккаунт

🔐 Безопасность – защита данных через аутентификацию Firebase и локальное шифрование

📱 Удобное управление – хронологический список всех паролей с возможностью поиска, редактирования и удаления

🔄 Смена мастер-пароля – безопасное изменение пароля с перешифровкой всех существующих данных

### 🛠️ Технологии

Kotlin + Jetpack Compose – современный декларативный UI

Firebase Firestore – облачная NoSQL база данных с реальным временем синхронизации

Firebase Authentication – безопасная аутентификация пользователей

Android KeyStore – защищенное хранение криптографических ключей на уровне ОС

MVVM – архитектура приложения с разделением ответственности

Coroutines + StateFlow – асинхронные операции и реактивное программирование

Navigation Component – навигация между экранами

Material Design 3 – современный дизайн системы

AES-256 + SHA-256 – алгоритмы шифрования для максимальной безопасности

### 🚀 Особенности реализации

Многоуровневая защита: Локальное шифрование через Android KeyStore + облачное шифрование через мастер-пароль

Сессионная безопасность: Ключи шифрования хранятся только в активной сессии

Реактивная синхронизация: Мгновенное обновление между устройствами через Firebase Firestore

Визуальная обратная связь: Понятная индикация требований к паролю

Material Design 3: Современный интерфейс с поддержкой темной темы

### 📊 Ключевые преимущества

Полная приватность: Только вы имеете доступ к своим данным благодаря end-to-end шифрованию

Кроссплатформенность: Доступ к паролям с любого Android-устройства

Простота использования: Интуитивно понятный интерфейс без лишних сложностей

Образовательная ценность: Практическое применение современных технологий мобильной разработки

Бесплатное решение: Использование бесплатного тарифа Firebase для хранения данных

### 🎓 Образовательный аспект

Проект демонстрирует комплексное применение:

Работы с системами безопасности Android (KeyStore, Cipher API)

Реализации многоуровневого шифрования данных

Интеграции с облачными сервисами Firebase (Auth, Firestore)

Создания полноценного MVP приложения с нуля

Принципов Material Design 3 и реактивного программирования

### 🔧 Технические детали

Минимальная версия: Android 8.0 (API 26)

Архитектура: Чистая MVVM с Repository паттерном

Шифрование: AES-256-GCM (локальное), AES-256-CBC (облачное)

Хранение ключей: Android KeyStore для максимальной безопасности

Синхронизация: Firebase Firestore с real-time слушателями

Навигация: Jetpack Navigation Component с графом навигации
